# ForestOfLight Technical Bedrock Hub

## Product

A technical product, documentation system, project-discovery surface, and release archive for ForestOfLight's public Minecraft Bedrock engineering work.

## Users

- technical Minecraft Bedrock players
- addon developers
- server operators
- builders
- existing Canopy users
- new users exploring the ecosystem

## Primary outcomes

1. Understand what ForestOfLight builds.
2. Reach every public repository quickly.
3. Understand Canopy as the flagship.
4. Find features, commands, rules, documentation, downloads, releases, and source.
5. Understand verified project relationships.

## Constraints

- preserve routes, archive structure, documentation, search, filters, shareable state, local downloads, and static generation
- keep Canopy as the flagship
- use no fabricated metrics, claims, relationships, or project states
- maintain zero visitor-time GitHub dependency
- remain accessible, responsive, fast, and maintainable
